# TicketCord

AI-powered Discord ticket bot platform serving 5,000+ servers.

Build a fully customizable support system with your own Discord bot — AI auto-routing, knowledge base, custom forms, web dashboard, analytics, and white-label branding.

**[Website](https://ticketcord.net)** · **[Documentation](https://docs.ticketcord.net)** · **[Discord](https://ticketcord.net/discord)** · **[Product Hunt](https://www.producthunt.com/products/ticketcord)**

### Features

- Custom ticket forms & panels
- AI-powered auto-routing & knowledge base
- Web dashboard with analytics
- 20+ Discord slash commands
- White-label branding (custom bot name, avatar, colors)
- Multi-language support (18 languages)
- SLA management & approval workflows
- Webhook integrations
