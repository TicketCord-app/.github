# TicketCord

A white-label Discord ticket bot with AI support. It runs under your own Discord application, so members see your bot's name and avatar, and you set everything up from a web dashboard. Every new account starts with a 14-day Enterprise trial, no card needed.

**[Website](https://ticketcord.com)** · **[Documentation](https://ticketcord.com/docs)** · **[Pricing](https://ticketcord.com/pricing)** · **[Discord](https://ticketcord.com/discord)** · **[Product Hunt](https://www.producthunt.com/products/ticketcord)**

### Features

- Ticket panels, forms, and welcome messages: [Configuration](https://ticketcord.com/docs/bot/configuration), [Welcome Messages](https://ticketcord.com/docs/configuration/welcome-messages)
- AI answers from your own [Knowledge Base](https://ticketcord.com/docs/ai/knowledge-base), with handoff to your staff
- [Auto-Route](https://ticketcord.com/docs/ai/auto-routing), [Priority Detection](https://ticketcord.com/docs/ai/priority-detection), [Duplicate Detection](https://ticketcord.com/docs/ai/duplicate-detection), and [Translation](https://ticketcord.com/docs/ai/translation)
- A web inbox and [analytics](https://ticketcord.com/docs/dashboard/analytics) across all your bots
- 30 [slash commands](https://ticketcord.com/docs/commands/overview) and a bot interface in 19 languages
- [SLA targets](https://ticketcord.com/docs/configuration/sla-management), [approval workflows](https://ticketcord.com/docs/configuration/approval-workflows), and [business hours](https://ticketcord.com/docs/configuration/business-hours)
- Signed [webhooks](https://ticketcord.com/docs/integrations/webhooks) for Zapier, Make, Slack, or your own service
- Connect [Claude Code or Codex](https://ticketcord.com/docs/ai/mcp) over MCP

New here? Start with the [Quick Start](https://ticketcord.com/docs/quickstart). Switching bots? Read the [Migration Guide](https://ticketcord.com/docs/support/migration).
